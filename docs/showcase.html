05 · FAQ

常见问题 · 四问速览FAQ · The four questions

Q.1这个项目解决什么问题？What problem does it solve?＋
想要 mojo.trade 那种「雕版图谱」质感时，每次都要从零逆向。本技能把整套语言工程化：token、motif、蓝图、文案腔调、replica 参照，一次提炼反复使用。That mojo.trade feel used to require reverse-engineering from scratch. This skill industrializes it: tokens, motifs, blueprints, copy voice, replica.
Q.2什么场景下用？能得到什么结果？In what scenario, with what outcome?＋
交易/金融产品 launch 页、waitlist 页、编辑感 hero——对 Agent 说「用 Mojo Plate 做」即得整套印刷纪律；手写时抄 tokens.css + sections.md 也能直接开工。Trading/fintech launch pages, waitlists, editorial heroes — ask your agent "use Mojo Plate" and the print discipline arrives whole.
Q.3内部是什么结构？How is it structured?＋
SKILL.md（触发 + 非协商规则）→ references/tokens.css（全 token + 工具类）→ references/motifs.svg（boil 滤镜 + 日纹 symbol 库）→ references/sections.md（四个蓝图 + 文案腔调）→ replica/（完整成品）。SKILL.md → tokens.css → motifs.svg → sections.md → replica/. Each layer usable alone.
Q.4我能复用 / 抄走什么？What can I reuse?＋
① 整包复制进 skills 目录即触发；② tokens.css 独立可用（换 accent 四件套一起换）；③ duotone 滤镜配方让任何图变标本版画；④ 「Plate I/II/III」图册叙事结构可套任何内容。Drop-in skill; standalone tokens.css; duotone recipe turns any image into a specimen plate; atlas narrative fits any content.
